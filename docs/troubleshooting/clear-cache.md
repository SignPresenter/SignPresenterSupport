# Clear Cache

<div className="article-intro">

Sometimes content doesn't download cleanly. Clearing the cache deletes anything broken so SignPresenter can re-download it fresh. This guide covers both the Fire Stick app cache and your browser cache.

</div>

:::warning
**Don't clear the Fire Stick cache while you're trying to run offline** — that deletes everything you've cached. See [Running offline](../screens/running-offline) for the offline workflow.
:::

## Clear the cache on a Fire Stick

Clear Cache is built right into the SignPresenter app menu — no need to dig through the Fire Stick settings anymore.

1. While SignPresenter is running, press **Back** on the remote to open the app menu.
2. Select **Clear Cache** in the right-hand menu.

   ![Clear Cache in the app menu](/img/player-menu-clear-cache.png)

3. Select your playlist (or **Run Schedule**) to start playing again.

SignPresenter will re-download all your content. This same menu also shows the screen name, app version, and free/used storage space — handy if support asks for them.

:::note Older app versions
If you don't see the menu, you're on an older build. Update the app, or clear the cache the old way: press **Home**, then go to **Settings → Applications → Manage Installed Applications → Sign Presenter → Clear cache**, then relaunch the app.
:::

## Clear the cache in Google Chrome

1. Click **Chrome** in the macOS menu bar (or the three-dot menu on Windows).

   ![Chrome menu](https://user-images.githubusercontent.com/65249159/153671005-4b425c30-4b5f-4c47-89ef-1ab98826b395.png)

2. Click **Clear Browsing Data**.

   ![Clear browsing data](https://user-images.githubusercontent.com/65249159/153671351-d5e16db8-e2ec-40e7-98af-757faa8fe2fb.png)

3. Set the time range to **All Time** and click **Clear Data**.

   ![All time](https://user-images.githubusercontent.com/65249159/153671526-c1e9eee3-c315-442c-8f3d-1dbb15c71716.png)
