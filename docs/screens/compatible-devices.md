## What about Fire Sticks?

### Older Fire Sticks (Fire OS) — still work

If you already own a Fire Stick running **Fire OS** (Android-based), it will continue to work with SignPresenter. No changes needed.

### Newer Fire Sticks (Vega OS) — limited support

The newest Fire Sticks run **Vega OS** instead of Fire OS. SignPresenter runs on Vega OS with the following limitations:

- **Vertical screen mode does not work** — horizontal content works fine
- **Does not auto-reboot** after a restart or when the Home button is pressed

For a reliable, fully-supported setup we recommend the onn. devices above instead of purchasing a new Fire Stick.
